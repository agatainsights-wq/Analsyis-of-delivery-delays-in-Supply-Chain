## Project Overview

This project was created as the final assignment for the Data Science & Business Analytics course.

The goal of the project was to analyze delivery delays within a supply chain using exploratory and predictive data analysis methods.

The analysis was performed using Python (Pandas, Scikit-learn) and Orange Data Mining on a real-world logistics dataset.

---

## Course Contents

- Data Analysis with Python
- Fundamentals of Machine Learning
- Fundamentals of Deep Learning

---

## Business Objective

The objective of the project was to identify patterns and key factors influencing delivery delays and to derive data-driven optimization recommendations for supply chain operations.

---

## Key Findings

One of the most important findings was that the selected shipping mode has a significant impact on delivery performance.

By switching to a more suitable shipping option, the risk of delivery delays can be significantly reduced.

# Analyse von Lieferverzögerungen in der Supply Chain

## Projektübersicht

Dieses Projekt wurde als Abschlussprojekt im Rahmen des Kurses „Data Science & Business Analytics“ durchgeführt.

Ziel des Projekts war die Analyse von Lieferverzögerungen innerhalb einer Supply Chain mithilfe explorativer und prädiktiver Datenanalyse.

Die Analyse wurde mit Python (Pandas, Scikit-learn) sowie Orange Data Mining auf Basis eines realen Datensatzes durchgeführt.

---

## Kursinhalte

- Datenanalyse mit Python
- Grundlagen von Machine Learning
- Grundlagen von Deep Learning

---

## Zielsetzung

Ziel des Projekts war die Identifikation von Mustern und Einflussfaktoren für Lieferverzögerungen sowie die Ableitung datenbasierter Optimierungsempfehlungen für Supply-Chain-Prozesse.

---

## Zentrale Erkenntnisse

Eine der wichtigsten Erkenntnisse war, dass die Wahl der Lieferoption einen signifikanten Einfluss auf die Lieferperformance hat.

Durch die Nutzung einer geeigneteren Versandart kann das Risiko von Lieferverzögerungen deutlich reduziert werden.
